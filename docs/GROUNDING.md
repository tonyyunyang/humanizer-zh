# 中文去 AI 味的编辑依据

Humanizer-zh 的目标是根据具体的表达需要润色中文和中英混排，减少模板化的措辞、结构、节奏和姿态，同时保住事实、立场和作者的声音。中文正确是基础，但一段话即使没有语法错误，也可能显得空泛、机械或过度表演。反过来，平直、重复、含蓄、排比和修辞都可能恰当地完成一次表达。

判断应从用户要求、上下文、原有语气和句段作用中产生，不按文体名称分配固定风格。清楚、简练、有力度、有回味等效果，是否值得追求，要看这一次想表达什么。原文平直不构成自动润色或增加文采的理由；表达需要表现力时，也应允许主动改进措辞、停顿、重点和呼应。

本页记录 2026-09-12 的依据与取舍，接续[此前的中文编辑调研](CHINESE-EDITING-RESEARCH.md)。它供维护者查证，不是日常改稿的额外必读文件。以下区分来源中的观察、本项目的编辑建议与尚待验证的假设；没有一份资料单独给出了普适的“AI 味检测规则”。

关于 issue、PR 和设计讨论如何支持定位与审阅，另见 [Writing useful issues and pull request descriptions](ISSUES-AND-PRS.md)。协作任务需要的信息选择与本页的中文表达原则共同适用，不能据此把所有文本统一压短。

## Wikipedia 怎样使用

本次固定阅读的版本为 `oldid=1374292905`，页面修订时间是 2026-09-11 02:32 UTC。该页自称经验建议页，并说明没有经过社区政策审定、部分最新模型相关内容待更新。它也明确提醒：所列现象可能出现在人类作品中，有些仅适用于 Wikipedia。[^1]

本项目将其用于提出编辑问题，例如检视空泛拔高、宣传式措辞、过度整齐的句式和正文外壳。是否改动，仍由当前上下文中的实际作用决定。该页关于单独使用转折词并不可靠的提醒尤其重要：不能把正常的“此外”“但是”或一次三项列举当作删除理由。[^1]

Wikipedia 的治理目标还包括来源可靠性等问题。因此，借鉴页面时应继续核对原有归属和事实边界，不能只换掉表面措辞，让没有依据的断言看起来更可信。本 skill 不评价作者身份，也不以通过检测器为目标。

## 专业编辑标准怎样支持表达目的

Editors Canada 的 2024 年标准将编辑置于读者、媒介、内容和目的的关系中。其风格编辑部分 C3.1 要求声音、语气、视角等与内容及作者意图相合；C5.2–C5.4 进一步要求检查实际效果、情绪与文字组织是否配合。[^2][^3]

据此，本项目采用一个操作原则：先理解这段话要产生什么效果，再选择适合的表达。具体动作可以是删冗余、改语序、重新安排重点，也可以是留下必要停顿，或者让原有细节在后文产生呼应。修改幅度以效果为依据，不能靠字数或修辞数量决定。

标准中的“改进清晰度”不意味着所有句子都应解释到底。“消除套话”也不意味着所有常见句式都没有用。编辑需要能说明改动如何帮助这一次表达，保留的写法又在发挥什么作用。对本项目，这种说明应留在编辑判断和评审中，不必变成用户每次都要填写的模式或档位。

以下英文建议不直接进入中文规则：普遍优先肯定句、按场景例子固定使用长短句、把所有“无趣”理解成应该增加戏剧性。它们有各自的背景，本项目保留依目的选择的原则。

## 中文依据怎样落到句子里

周立炜、饶高琦的中文语体能力研究把合适表达与具体语域中的交际联系起来，并区分识别、生成与转换等能力。这为检查“同一素材能否服务不同要求”提供了方法启发。本轮只取得公开摘要，不用其中对旧模型的评价推断当前模型表现。[^4]

中文里的小词、语序、省略和停顿经常共同表达关系。陈振宇、刘林对“才”的研究涉及必要条件与主观预期；蒋平关于零形指代的研究提醒，省略后的所指有时并不唯一。这些资料支持结合具体语境保留含义，不能导出“主语越少越好”或“每个指代都必须解释”的通用规定。[^6][^7]

老舍关于文学语言的讨论同时涉及普通词语、上下句联系与个人风格。可吸收的是把语言放回具体内容和感受中处理；不能把其中的短句偏好推广到每一次写作，更不需要模仿其个人文风。[^5]

对本项目，合适的中文至少包括三个层面：句子成立，关系和分寸准确，读起来的节奏与这次表达相合。词语熟悉并不保证搭配自然，句子没有语法错误也不保证前后承接自然；有意的省略和留白又不应被当作错误补满。

## AI 味的工作定义

这里把“AI 味”作为编辑目标的简称：原本应该服务于具体内容的表达，被可替换、可批量套用的说法占据，读者感到程式化或不贴切。判断针对这一段文字的效果，不针对它究竟由谁写成。

下面是本项目结合当前规则和前测提出的编辑检查项，不是研究证明的中文检测特征，也不是出现即改的清单。

| 可观察的问题 | 值得改的原因 | 应保留的情况 |
| --- | --- | --- |
| 先抬高意义，再绕到具体内容 | 姿态遮住了真正要说的事 | 作者确实在评价意义，或前文已经建立了相关论证 |
| 抽象名词替代具体关系 | 读者不知道谁做了什么、影响落在哪里 | 有明确所指的概念、术语，以及有意保持概括的表达 |
| 多个段落反复使用同一种铺垫和收束 | 节奏与内容脱节，下一句的形状可以机械预料 | 排比、回扣或反复本身就在表达态度、时间或强调 |
| 凭空安排反对者、安慰或亲密感 | 替作者或读者补了未给出的心理与关系 | 真实的异议、礼貌、歉意、让步和原有亲近语气 |
| 不断解释已经表达出来的感受 | 读者能领会的部分被重复说透 | 本次确实需要明确解释，或读者缺少必要背景 |
| 清理后换成另一套“人味”模板 | 只是把公文化变成碎句、热梗或强行感慨 | 作者原有且与任务相合的口语、节奏、幽默和修辞 |

这些问题都可能出现在人写的稿件中。去 AI 味的收益应表现为表达更贴切、模板痕迹减少，而非某些词出现得更少。保真仍然成立：不能用编造的街景、亲身经历、数据或心理活动来补所谓的具体和生动。

## 词频与创作研究带来的边界

Kobak 等人的研究追踪了大规模生物医学摘要的词汇变化，观察到部分风格词频率的明显变化。Juzek 与 Ward 也研究了科学英语中的词汇过度使用，并讨论其可能来源及证据局限。这些研究说明某些语言习惯可以在群体层面观察，但研究对象、时期和语言都很具体。[^8][^9]

因此，不能把英文中的高频词逐字翻译成中文黑名单，也不能认为删掉一组词就完成了编辑。中文候选规则必须有自己的语境、修改例子、保留反例和实际输出证据。对历史模型的发现也不应被包装成当前所有模型的固定行为。

Doshi 与 Hauser 的短故事实验发现，获得生成式 AI 创意帮助的作品可能被评价为更好，同时作品之间更相似。这支持检查“单篇看起来更顺”与“多篇越来越像”两个不同问题；它并不证明某种中文修辞一定来自 AI，也不意味着应该故意写得不规则。[^10]

本项目据此增加一个跨案例问题：不同的要求是否仍得到同一种声音、同一种起承转合？如果是，需要检查模型是否在套固定风格，而不只看每篇是否通顺。

## 把依据转成可验证的判断

原则不能只停在“贴切”“有表现力”等抽象词上。当前最小验证单元采用同一份原文配不同的用户要求，再比较输出怎样改变重点、力度、解释程度或停顿。改变的是这一次需要完成的表达，不是文体标签。

例如，同样的安排中，一个读者需要决定什么时候完成付款，另一个读者已经付款、只想弄清状态为何没更新。信息都要保住，先说什么却应不同。同样一段包含道歉和不满的文字，也可能分别需要先修复沟通或先明确影响；两个目的都不授权编造对方动机。

这类对照不提供唯一标准答案。评审需要判断输出是否确实回应了当前需要，是否仍是自然中文，是否处理了妨碍表达的模板习惯，以及是否保住原有事实和态度。原文已经合适时，少改或不改也应得到肯定；表达效果尚未实现时，单纯保留原文不自动算成功。

对表现力的检查也应具体：想让人感到迟疑时，停顿是否起作用；想把界限说清时，力度是否来自已有事实和要求；只需交代状况时，是否加入了不必要的表演。不会设置“文学性分数”，更不会要求每段有比喻、每篇有余味。

## 评审器也需要校准

LLM-as-a-Judge 研究讨论了位置、篇幅、自我偏好等偏差。因而，匿名比较本身还不够；评审器必须被检查是否在奖励自己的固定文风。[^11]

本轮先使用小型校准材料：同一对表达面对不同目标时，偏好应能改变；事实相同而多了无作用的模板外壳时，应能说明具体问题；完全相同的输出应允许平局。关键偏好再互换 A/B 顺序检查。校准失败优先修评审方法，不让 skill 迎合错误的评分方向。

后续评审显式记录推断出的表达目标，以及可定位的模板问题。事实、范围或精确字符错误仍单列，不能用读感补分。纯审美取舍允许平局和不确定，不因为某版更短、词更大或句子更有起伏就计胜。

研究只提供可检验的出发点。是否在本项目有帮助，还需要固定版本、独立会话、新案例及重复检查。来自同一模型家族的评审和合成材料仍有局限，真实作者或中文编辑的反馈应继续进入下一轮。

## 本轮的取舍

| 决定 | 依据与理由 |
| --- | --- |
| 采用按表达目的选择修改方向 | 符合最新目标，也得到专业编辑原则支持；不会增加文体路由或用户选档 |
| 继续保留常见模板问题的具体提示 | 有助于观察 AI 味，但每项都要连同上下文作用和保留情形理解 |
| 允许主动改进已有意思的表现方式 | 表达可以通过措辞、语序、停顿和呼应改善，事实与立场边界继续保留 |
| 更新例子与评审，不单纯增加规则 | 当前缺口涉及默认目标和评价取向，堆叠更多例外难以解决 |
| 不采用英文词表、句长配额、统一口语或统一文采 | 缺少普适证据，也会违背不同表达目的 |
| 保存来源、版本、采用和跳过理由 | 便于后续检查依据是否变化，研究内容不成为第二份运行入口 |
