## 当前决定

当前可用起点仍是 `a03e047`。匿名开发集比较在 README 搜索说明中偏好重写前的输出，理由是检索范围与排除条件放在一起，读者更容易定位。两版均通过信息检查，这是一项可检验的结构改进线索，不是硬错误。

第一个实验候选 `8cb2e9b` 只在“接住上文，再往下说”中加一句：说明文里，同一问题的条件与限制尽量就近交代。开发集的匿名比较得到 5 个平局、1 个偏好原版；原版重复运行也能把相关信息放在一起。新增提示没有显示稳定收益，决定撤回，不把一次偏好直接写成进步。

保留集 `fresh-zh-holdout-02` 暴露了更具体的问题：用户要求不要新增结尾的平衡说理，原文同时明确保留了别人选择打卡的自由。原版和第一个候选都删去了这项已有的立场限定。已核对原始请求和两个输出，确认问题不只是评审的审美偏好。此例从此转为第二轮的开发回归材料，第二轮另请独立会话编写新的保留集。
