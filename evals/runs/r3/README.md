# 第三轮：表达目的与去模板效果

本轮依据最新约定更新目标：顺着用户要求、上下文与句段作用编辑，不按文体名称设固定风格，不以更短、口语化或更多修辞为统一方向。专业依据和适用限制见 [GROUNDING.md](../../../docs/GROUNDING.md)。

保留 `e4946cf`，作为新目标下的起点。16 份改稿通过本轮评审的信息与范围门槛，但没有建立新版优于旧版的稳定证据。八项初次比较中七项平局、一项略偏新版；这一微弱偏好在互换顺序后变成平局，不能计为确认的收益。完整结果见 [summary.json](summary.json)。

## 固定设置

- 对照：`97e6c21`，即前两轮结束后的规则。
- 候选：`e4946cf`，156 行；调整开头与回读目标，移除文体举例式的默认选择，允许按需要主动改善表达，并用同一雨景的两种用途说明停顿选择。
- 编辑与评审：`gpt-6-astra`、`max`，隔离的新会话，CLI 版本及内容哈希见各 manifest。
- 案例：独立会话编写四组原文，每组两个不同要求，共八项任务。两组开发、两组保留；同组不跨分区，候选固定前未打开保留组输入与预期。
- 生成超时 240 秒，评审超时 300 秒；两侧生成的模型、推理档位与超时一致，并发数按服务状况采用 1 或 2，具体记录在 manifest。
- 本次交互式建环完成 7 次校准、16 次编辑、8 次匿名比较及 1 次顺序复核，共 32 次有效执行。另外保留 4 次服务容量失败，共 36 次调用尝试。未来定期任务每次至多 16 次编辑或评审调用，失败重试也计入。

## 新评审标准

评审先说出具体表达目标，再核对实质信息与明确范围，最后比较目的适切性、自然中文和去模板效果。需要表现力时检查语言是否起作用；平直已经合适时允许保留。评审单独定位改稿中的模板问题，不从单个词、一次排比或一个短句判断作者身份。

这版评审标准与前两轮不同，旧偏好计数不混入新结果。完整提示在各匿名任务文件中，schema 与提示哈希分别留存。新目标来自用户的明确修订；即使有限样本没有显示总体优势，也不据此退回已被否定的固定风格选择。

## 校准

四个基础校准已按事先声明的预期完成：同一雨景在“直接交代状况”和“让读者稍作停留”下偏好不同；没有作用的模板外壳被定位；相同输出判为平局。原文、两个输出及维护代理预先声明的期望保存在 [intent-fixtures.json](../../calibration/intent-fixtures.json)，期望没有传入评审提示。

另对前三项互换 A/B 位置，三项偏好均随身份映射一致，共 7/7 项符合预期。校准只用于检查评审器，没有将它计入 skill 的改写收益，也不代表评审器在所有材料上可靠。雨景同时用于正文示例，因此更不能充作独立的 skill 测试。

评审没有在这 16 份输出中标出可定位的无效模板问题。它只说明这些合成案例中没有被发现的问题，不能解释成模板已经全部去除。

- **同一安排、不同疑问。** 两版都能对尚未付款的人先交代付款时限，对已付款的人先解开重复付款的疑问，同时保留精确字符、价格和状态更新条件。
- **同一歉意与不满、不同分量。** 两版都按请求调整重点，保住道歉、约定、实际影响和下一次要求，没有增添威胁或替对方猜动机。
- **原本合适的平直表达。** 薄荷案例中，两版都能区分请同住者照看与向旁人讲近况，没有追加养护知识或焦虑。唯一初次偏好来自新版首句提前交代“窗台上的两盆”；互换后评审认为差异不足，改判平局。保留两次判断，不用重跑挑出喜欢的结果。
- **让细节承担意味。** 换灯案例中，两版都删除了“生活质量的跃迁”等泛化升华。需要交代变化时，保留前后对照与个人经历；需要停留时，把“还是停了半步”独立成段，保住菜袋碰到栏杆的声音。新版额外断开“灯亮着”一句，评审认为两种节奏各有取舍，未形成明确优势。

原始生成分别在 `baseline-development/`、`candidate-development/`、`baseline-holdout/` 与 `candidate-holdout/`。匿名材料、映射和原始评审在 `blind-development/`、`blind-holdout/`；顺序复核在 `blind-order-check/`。维护代理也回看了原文与实际改稿；本轮没有人类作者或专业中文编辑盲评。

## 执行失败与补跑

`candidate-holdout/r3-holdout-02-b-1.json` 和开发组的三项评审遇到模型服务容量不足，没有返回成稿。这些是执行失败，不计成信息或文风失败；首次批次的 `incomplete` 状态保持不动。

仅补跑这四项缺失输出，使用相同提示、模型、推理设置和超时。`candidate-holdout-retry1/`、`blind-development/retry1/` 留存补跑结果。恢复脚本核对设置与提示哈希后，将可用记录逐字节复制到 `candidate-holdout-complete/`、`blind-development/reviews-complete/` 两个新目录，用于后续比较。其 manifest 明确标为派生视图，记录来源和全部失败，不重复计为模型调用。

本轮修改维护脚本后，仓库结构校验和 27 项单元测试通过；恢复脚本也实际完成了上述两组整理。结构检查、运行成功、校准正确和改稿质量在记录中分开处理。

## 取舍与下一步

这轮落实了用户对编辑目标的修订，也校准了相应的评审方式。保留目的导向的规则，不将它宣传成已经实证胜过旧版。实际比较没有发现需要撤回的信息错误；唯一微弱偏好不稳定，因此不继续围绕它增加正文规则。

四组原文、八项任务的规模很小，每版每项只生成一次。请求已经把预期效果说得较明确；对含蓄要求、较长上下文和同一段中多种作用的判断，证据仍不够。模型生成和模型评审也可能共享偏好。这轮未重跑全部 28 个永久案例、真实文件编辑或其他模型，不能替代发布前的完整回归。

下一轮优先寻找需要从上下文推断表达目的的材料，同时检查不同文章是否被改成相同的声音与起承转合。八项案例均已消耗，之后只作为开发材料；需要新的保留集或真实作者反馈，不把反复测试同一组材料当成持续进步。
